# PIONIERAT landing page

One-page Ukrainian website for selling the PIONIERAT board game.

## Run locally

```bash
python3 -m http.server 4173
```

Open: `http://127.0.0.1:4173`

## Order notifications

The form sends orders via FormSubmit. Update `index.html`:

- replace `https://formsubmit.co/your-email@example.com` with your email.

Supported payment methods shown on the page:
- Monobank
- Visa
- Mastercard
